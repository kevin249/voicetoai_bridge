# v0.1 真机验收

以下为待执行的真机检查，不代表已通过。请记录设备、Android 版本、桥接 commit、客户端包名 / 版本、UI 语言，以及客户端是否设置自动进入语音。

| 场景 | 操作 | 预期 |
|---|---|---|
| 首次权限 | 拒绝麦克风后开始，再授权 | 明确提示，无崩溃，授权后能监听 |
| 无障碍关闭 | 未启用服务时测试 | 提示启用，不启动点击流程 |
| 离线唤醒 | 断网，说选定唤醒词 | 桥接能检测；官方 AI 服务可能因断网不可用 |
| 唤醒准确率 | 安静环境 20 次；背景人声观察 30 分钟 | 记录成功、漏检、误唤醒、延迟，不事先宣称达标 |
| 按钮测试 | 两个客户端分别测试 | 进入连续语音，不能误点文字听写 |
| 学习 | 学习后手动点击 Live；结束语音后测试 | 保存并重现点击；无可用节点则提示失败 |
| 自定义 | 配置启动 / 界面包名后学习 | 只能操作白名单界面 |
| 已有语音 | 在语音界面测试 | 匹配活动标记则不再点击；缺失时补规则 |
| 歧义 | 配置匹配多个按钮的标签 | 停止，不随机选择 |
| 弹窗 | 登录 / 权限 / 其他 App 界面 | 不代替登录授权、不跨包点击、12 秒超时 |
| 麦克风交接 | 唤醒后说话；结束后恢复 | AI 能录音，对话期间桥接无 AudioRecord，恢复后能再次唤醒 |
| 后台会话 | AI 仍后台录音时恢复 | 系统报告占用时阻止；设备不可准确报告时需先手动结束 |
| 取消 | 模型载入 / 查找按钮期间停止 | 旧回调不再启动或点击客户端 |
| 快速操作 | 开始、停止、测试、开始 | 无并发录音、无 JNI use-after-free |
| 锁屏 | 锁屏时唤醒 | 提示亮屏解锁，不解锁、不盲点 |
| 杀进程 | 重开应用 | 默认未监听，无旧任务回调 |
| 改配置 | 监听时切客户端 / 唤醒词 | 停止旧任务，需重新开始 |
| 接电持续运行 | 监听 1–2 小时 | 记录温度、耗电、后台限制 |

人工诊断命令：

```bash
adb install -r app/build/outputs/apk/debug/app-debug.apk
adb shell dumpsys package com.openai.chatgpt
adb shell dumpsys package com.google.android.apps.bard
adb shell dumpsys audio
adb shell uiautomator dump /sdcard/voice-window.xml
adb pull /sdcard/voice-window.xml
```

界面转储可能包含当前聊天内容，只在本地查按钮 `resource-id` / `content-desc`，不要上传公共仓库；测试完删除。桥接自身不会生成此转储。
